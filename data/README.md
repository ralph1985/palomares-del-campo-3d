# Datos de Palomares del Campo

`palomares.osm` es una exportación acotada obtenida de la API de OpenStreetMap para el núcleo del municipio y sus alrededores. El script `scripts/osm_to_geojson.py` genera `public/data/palomares.geojson` para el visor.

Los datos de OpenStreetMap están disponibles bajo la licencia Open Database License (ODbL) y requieren atribución a sus colaboradores.
